# 千軍令 — 三國戰役指揮（warGame）

3D 三國真實戰役指揮遊戲：不蓋房子、不採集，你就是一場會戰的主帥。指揮數千名士兵佈陣、包抄、衝鋒，派奇兵燒掉敵軍糧倉，看著敵軍士氣崩潰全線潰逃。美術與介面參考部落戰爭 Clash of Clans。

規劃書：[`docs/`](docs/00-專案總覽.md)

**線上試玩**：https://wenbatman33.github.io/warGame/ （網址加 `?dev=1` 後按 `D` 開 DEV 微調工具）

## 進度

- [x] M0 規劃書與骨架
- [ ] M1 千軍戰場（地形、光影、5,000 名士兵實例化）
- [ ] M2 軍團指揮（陣型、尋路、選取、畫戰線）
- [ ] M3 戰鬥與士氣（近戰、箭雨、衝鋒、潰逃、武將）
- [ ] M4 糧草與 AI（燒糧、斷糧、敵軍指揮官）
- [ ] M5 CoC 式介面（選單、戰役地圖、部署、卡片、結算）
- [ ] M6 真實戰役（官渡、赤壁、合肥、夷陵、街亭）
- [ ] M7 打磨（生圖、音效、特效、效能）
