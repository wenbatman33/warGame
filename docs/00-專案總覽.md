# 00 — 專案總覽

> 專案代號 `warGame`，遊戲名《千軍令》（副標：三國戰役指揮）。
> 取代 `ageOfEmpires`（Q 版 RTS ＋ 經濟建設）的新方向：**不蓋房子、不採集，玩家就是一場真實戰役的主帥**。
> 規劃書於 2026-10-02 由使用者授權「一律同意」，各里程碑完成即 commit ＋ push。

---

## 1. 北極星

| 項目 | 定義 |
|---|---|
| 一句話 | 指揮數千名士兵的三國真實戰役：佈陣、包抄、衝鋒，派奇兵燒掉敵軍糧倉，看著敵軍士氣崩潰全線潰逃 |
| 致敬 | 全軍破敵（軍團、陣型、士氣、側擊）＋ 部落戰爭 Clash of Clans（美術、卡片式 UI、三星評價、戰役地圖） |
| 核心體驗 | 一場 8–15 分鐘：部署 1 分鐘 → 接戰 → 關鍵時刻的奇襲／計策 → 敵軍潰散的高潮 |
| 平台 | Web：PC 瀏覽器為主、手機瀏覽器（橫向）可玩 |
| 模式 | 戰役（真實三國戰役劇本，含三星評價）＋ 自訂會戰（自選兵力、地形） |
| 成功公式 | 開場 10 秒內看到千軍對陣的壯觀 ＋ 第一場內學會「燒糧 → 敵軍士氣崩潰」 ＋ 每場結束都想拿滿三星 |

## 2. 設計支柱

| # | 支柱 | 具體規則 |
|---|---|---|
| 1 | **千軍萬馬** | 畫面上同時有 2,000–5,000 名可見士兵（每名代表 10 人），每個人都有自己的動作與生死；軍團以陣型移動 |
| 2 | **主帥視角，不是保姆** | 只指揮「軍團」不指揮個人；沒有經濟、沒有建造；所有心力花在陣型、時機、兵種相剋 |
| 3 | **士氣決定勝負** | 很少有軍團被殺光，絕大多數是**士氣崩潰而潰逃**；側擊、背襲、武將陣亡、斷糧都打在士氣上 |
| 4 | **糧草是命脈** | 每支軍隊有糧倉與輜重線；燒掉敵方糧倉 → 立即士氣重挫 ＋ 後續斷糧（攻防速全面下降、逃兵）。官渡烏巢就是範本 |
| 5 | **一眼看懂** | CoC 式飽和色彩與厚描邊 UI；每個軍團頭上有勢力旗號；狀態（動搖、斷糧、潰逃）用大圖示表示 |

## 3. 已定案決策

| 決策 | 選擇 | 影響 |
|---|---|---|
| 技術 | Vite ＋ TypeScript ＋ Three.js（WebGL2） | 與前專案同一套；士兵用 InstancedMesh ＋ VAT 頂點動畫，一個兵種一次 draw call |
| 美術 | **CoC 風格的寫實比例**：頭身比約 1:6（不是 Q 版 1:2），飽和暖色光、柔和陰影、厚實圓潤的道具 | 程式建模（不依賴外部模型檔）；頭像、Logo、背景用 AI 生圖 |
| 規模 | 每方 6–20 個軍團、每軍團 24–120 名士兵；1 名士兵 ＝ 10 人 | 效能預算見 05 |
| 時間 | 即時制，可暫停下令（空白鍵）、0.5×／1×／2× 速度 | 手機友善：暫停時也能下令 |
| 模擬 | 固定 30 Hz 模擬 ＋ 渲染插值；**不做**多人連線 | 不需要定點數與確定性，程式簡單很多 |
| 部署 | GitHub `wenbatman33/warGame` → Actions 建置 → `gh-pages` 分支 → GitHub Pages | https://wenbatman33.github.io/warGame/ ；網址加 `?dev=1` 開 DEV 工具 |
| 推版 | 本專案各里程碑完成即 commit ＋ push（使用者 2026-10-02 授權） | |

## 5. 用語表

| 遊戲內 | 意義 | 程式 id |
|---|---|---|
| 軍團 | 玩家能下令的最小單位（一群士兵＋可選的武將） | `Regiment` |
| 士兵 | 畫面上的單一模型，代表 10 人 | `soldier`（SoA 陣列索引） |
| 兵力 | 軍團剩餘士兵數 × 10 | `strength` |
| 士氣 | 軍團戰意 0–100；< 15 潰逃 | `morale` |
| 全軍士氣 | 依兵力加權的全軍平均；歸零即戰敗 | `armyMorale` |
| 體力 | 0–100；奔跑、衝鋒、肉搏會消耗 | `stamina` |
| 糧倉 | 後方囤糧點，可被焚燒 | `depot` |
| 本陣 | 主帥大營，囤前線糧草 | `hq` |
| 輜重車 | 從糧倉運糧到本陣的車隊 | `wagon` |
| 糧況 | 充足／吃緊／斷糧 | `supplyState` |
| 軍令點 | 施放計策的資源，隨時間回復 | `command` |
| 計策 | 主帥技能卡（擂鼓、火矢…） | `stratagem` |
| 武將技 | 武將的主動技能 | `ability` |
