# 09 — 遊戲性重新規劃（2026-10-03）

> 使用者回饋：「我要良好的策略型遊戲，不是武力展示的遊戲；12 歲的小孩也要適合玩；不應該是亂指揮的遊戲。」
> 這份文件從頭想一次「這個遊戲到底要讓玩家做什麼決定」。使用者出門前要求晚上驗收，所以先做第一階段原型（博望坡）供試玩。

---

## 1. 為什麼現在像「亂指揮」

| 問題 | 根本原因 |
|---|---|
| 手忙腳亂 | **即時制**：十幾支部隊同時在動，玩家要一直點、一直救火，拚的是手速不是腦袋 |
| 看不懂勝負 | 戰鬥是幾千個士兵各自互砍，結果由十幾個看不見的倍率決定（相剋、方向、士氣、糧況、地形…） |
| 計謀不好用 | 誘敵、伏兵、火攻這些「三國的精髓」，要靠玩家在混戰中精準操作，幾乎做不到 |
| 武力展示 | 畫面在比誰的兵多、誰砍得快，而不是比誰的計策好 |
| 不適合 12 歲 | 規則多、節奏快、因果看不見，失敗了也不知道錯在哪 |

**結論：問題不在數值調整，而在遊戲的基本形態。**

---

## 2. 新的設計目標

| 目標 | 意思 |
|---|---|
| **想清楚再下令** | 沒有時間壓力：下令時時間是停的，想多久都可以 |
| **一眼看懂** | 每邊只有 4～7 支部隊（每支＝一位武將＋一種兵），大圖示、大數字 |
| **先看到後果** | 下令前就顯示預估結果：「我軍損失約 200、敵軍約 600，勝算：高」 |
| **以謀勝力** | 兵少的一方靠計策贏：誘敵、伏兵、火攻、斷糧、守險。硬拚一定輸 |
| **像歷史解謎** | 每場戰役是一道「史實計策題」，有標準解法（照史實），也有別的解法 |
| **一場 10～15 分鐘** | 約 8～12 回合，小孩坐得住 |

---

## 3. 核心玩法：地點地圖 ＋ 手指滑動指揮（2026-10-03 依回饋改版）

> 使用者：「善用手指滑動的操作去指揮，不應該是三國志遊戲的思維；手機世代，手勢是玩策略遊戲最直覺的方式。」
> → 不做選單式回合制。**用手指從部隊滑到目標就是下令**；隨時可以暫停，暫停中一樣能滑動下令（想清楚再下令）。

### 3.1 戰場＝地點與道路
- 戰場分成 10～15 個**地點**，用道路連起來；部隊沿道路行軍。畫面仍是 3D 戰場，地點與道路直接畫在地上。
- 地點的地形決定能用什麼計策：

| 地點 | 效果 |
|---|---|
| 🌲 森林 | 停在裡面會**埋伏**（敵人看不見）；可以被**火攻** |
| 🌾 草地、蘆葦 | 可以被**火攻** |
| ⛰ 高地 | 防守 +50% |
| 🌊 渡口 | 在裡面的部隊戰力 −50%（**半渡而擊**） |
| 🚪 隘口、橋 | 防守 +50% |
| 🍚 糧倉、🏯 本陣 | 補給來源、主帥所在 |

### 3.2 滑動手勢（全部的操作）

| 手勢 | 命令 |
|---|---|
| 從我軍部隊**滑到一個地點** | 🚶 沿道路移動過去；滑到森林＝到了自動 🌲 埋伏 |
| 從我軍部隊**滑到敵軍** | ⚔ 進攻。**手指還沒放開就顯示勝算與預估損失** |
| 從我軍部隊**滑過敵軍、再滑到後方地點** | 🎣 誘敵：上前挑釁後撤到那個地點，敵軍（看性格）會追過去——掉進伏兵或火場 |
| 把**計策卡拖到地點**上 | 🔥 火攻、🥁 擂鼓、👁 偵察（像部落衝突放法術） |
| 點一下部隊 | 看資訊（兵力、士氣、剋／怕、狀態） |
| 在空白處拖曳／雙指 | 移動、縮放鏡頭 |

- 停下來的部隊自動**固守**（防守加成），不需要按鈕。
- 每邊只有 4～7 支部隊，一眼看得完。

### 3.3 敵軍的意圖看得到
- 看得到的敵軍，行軍路線會畫成紅色虛線箭頭（他要去哪裡一目瞭然）。
- 敵將有**性格**：夏侯惇「輕敵」（一定上鉤）、普通（六成）、謹慎（兩成）。

### 3.4 戰力一看就懂
- 每支部隊只有三個數字：**兵力**、**士氣**、**糧**。
- 交戰結果＝雙方「戰力」比一比，而戰力的計算全部攤開：

```
戰力 ＝ 兵力 × 兵種相剋 × 地形 × 士氣 × 糧況 × 計策
例：關羽 2000 刀盾，伏擊 ×2，對上夏侯惇 4000 長槍（中伏、在火中 ×0.5）
    我方戰力 4000  vs  敵方戰力 2000 → 大勝
```

- 滑去進攻時（手指還沒放開）就顯示**預估戰果**與**勝算**（高／中／低）。玩家知道為什麼會贏、為什麼會輸。
- 兵種相剋只剩一個圓圈：**槍剋騎、騎剋弓、弓剋槍**（刀盾是萬用的前排）。

### 3.5 糧道（保留，而且更清楚）
- 每支部隊要能沿著己方控制的道路連回糧倉，**連得上＝有糧**，斷了＝下回合起戰力 −30%，每回合士氣 −10。
- 糧道是一條條「路」，誰佔了路上的地點誰就切斷它，一眼看得懂。
- 部署階段要決定**派誰守糧道**、**糧營放在哪個地點**。

## 4. 示範：博望坡用新玩法怎麼打

| 步驟 | 手勢 | 畫面 |
|---|---|---|
| 1 | 關羽滑到豫山、張飛滑到安林（兩片樹林），按開戰 | 兩支部隊進林，停下後顯示「🌲埋伏中」，敵軍看不見 |
| 2 | 趙雲滑過夏侯惇、再滑回博望坡 | 趙雲挑釁後撤退，夏侯惇（輕敵）追進蘆葦地，**中計慌亂 8 秒**；趙雲自動再退一站 |
| 3 | 把「🔥 火攻」卡拖到博望坡 | 谷中蘆葦大火，曹軍兵力、士氣下滑 |
| 4 | 關羽、張飛滑到火中的夏侯惇 | 伏兵左右殺出（伏擊 ×2、敵軍中伏士氣 −25），勝算顯示「與關羽夾擊 → 高」 |
| 5 | — | 夏侯惇士氣崩潰敗走 → **勝利**（約 1 分鐘、三星） |

如果玩家不用計策、直接滑去進攻：手指還沒放開就顯示**勝算「低」**，畫面直接告訴他這樣打不贏，要想別的辦法。

## 5. 保留與改變

| 保留 | 改變 |
|---|---|
| 3D 戰場、地形、模型、動作、配樂、音效 | 點選單逐團操作 → **手指滑動指揮（可暫停）** |
| 九場史實戰役＋劇情、作戰步驟引導 | 十幾團部隊 → **每邊 4～7 支武將部隊** |
| 兵種相剋、糧道、士氣、地形、計策 | 看不見的倍率 → **公開的戰力公式＋預估戰果** |
| 伏兵、誘敵、火攻 | 交戰改成「依公開公式結算＋3D 演出」 |

**第一階段做完先給你試玩**，方向不對就在這裡改，不會一路做到底才發現。

## 7. 第一階段實作狀態（2026-10-03，給試玩驗收）

**怎麼玩**：戰役地圖選「博望坡之戰（新玩法）」，或直接開 `?battle=bowang`。開場是暫停的，可以先下好命令再按「▶ 開戰」。

| 項目 | 做法 | 程式 |
|---|---|---|
| 地點地圖 | 12 個地點＋道路，貼地圓環顏色＝誰佔領（藍我、紅敵、橘起火、黃＝拖曳目標） | `src/render/nodeMap.ts` |
| 棋盤視角 | 鏡頭轉 90°、俯角 70°：新野在左、曹營在右，依螢幕長寬比自動拉遠，手機橫放也看得到整條戰線 | `battle.ts`、`input/camera.ts pitchOverride` |
| 滑動指揮 | 部隊→地點＝移動（森林＝埋伏）；部隊→敵軍＝進攻（放手前顯示勝算、預估損失、加成來源）；部隊→滑過敵軍→地點＝誘敵；計策卡拖到地點 | `src/ui/nodeHud.ts` |
| 誘敵 | 滑過敵群自動挑最容易上鉤的（輕敵 100%／普通 60%／謹慎 20%），並列出可能跟著追的部隊；追到陷阱點**中計慌亂 8 秒**＋提示「快放火、伏兵殺出！」 | `node/game.ts provoke / lureTarget` |
| 佈陣時間 | 敵軍開場在北谷口紮營 40 秒（被挑釁、被打會立刻反應），斥候提示倒數 | `enemyHold` |
| 勝負 | 主帥**士氣崩潰**或兵力剩四成以下＝敗走（全軍敗退）；全軍剩三成五＝潰敗；本陣被佔 8 秒＝陷落 | `checkEnd / breakOff` |
| 防守不吃虧 | **正面寬度**：一支部隊同時最多被「自身兵力 × 2.5」的敵軍有效打到；待命部隊會自動保護主帥與本陣（森林裡的伏兵不動，等你下令）；敵軍逼近本陣會警報 | `frontCap / guard / hqAlarm` |
| 夾擊 | 勝算預估會把已在打同一目標的友軍算進去（「與關羽夾擊」） | `preview` |
| 敵軍 AI | 依性格決定進攻與上鉤；主帥被打全員回援；士氣低落（< 35）退回重整 | `ai` |
| 3D 演出 | 交戰由規則核心結算，3D 士兵只跟「正在交戰」的敵軍互砍（撤退的部隊不會被黏住） | `world.canFight` |

**平衡驗證**（`tests/node.test.ts`＋手動模擬）：

| 打法 | 結果 |
|---|---|
| 照作戰步驟（伏兵→誘敵→放火→伏兵殺出） | 約 50～80 秒勝，三星 |
| 誘敵＋放火後死守南谷口 | 勝，但損失較大 |
| 只伏兵不放火、或伏兵沒殺出 | 多半敗 |
| 正面硬拚、什麼都不做 | 敗 |
| 放火太晚、之後不管 | 諸葛亮被圍也撐得過 20 秒（有時間反應） |

**還沒做**：其他八場戰役仍是舊的即時指揮玩法；新玩法的 DEV 微調工具（拖曳地點位置、匯出）；難度分級。
