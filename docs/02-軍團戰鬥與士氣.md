## 2. 軍團與陣型

- 軍團 ＝ 一面旗號 ＋ N 名士兵 ＋（可選）武將。玩家只對軍團下令。
- 每名士兵有一個**陣位**（相對軍團中心的偏移）；軍團中心沿路徑前進，士兵追自己的陣位，太遠會跑步追上。
- 接戰時士兵脫離陣位找最近的敵兵打，但被繫在陣位 15 m 內，不會亂追。

| 陣型 | 排列 | 效果 |
|---|---|---|
| 橫陣 `line` | 寬 ≈ 3× 深 | 預設；接觸面大 |
| 方陣 `square` | 寬 ＝ 深 | 側擊、背襲懲罰減半；移動 −15% |
| 鋒矢 `wedge` | 三角形 | 騎兵衝鋒加成 ＋30%；步兵衝擊士氣傷害 ＋ |
| 散陣 `loose` | 間距 ×1.8 | 受箭傷 −40%、近戰防禦 −20% |

## 3. 戰鬥模型

### 3.1 近戰（每名士兵獨立）

- 每 1.2 秒（騎兵 1.0）攻擊一次身邊 1.6 m（騎兵 2.2 m）內的目標。
- 命中率 ＝ clamp(0.55 ＋ (攻 − 防) × 0.02 ＋ 修正, 0.1, 0.92)
- 傷害 ＝ 基礎傷害 × 方位（正面 1.0／側面 1.3／背面 1.6）× 士氣狀態 × 糧況 × 體力 × 地形高低（上坡打下坡 ×1.15）× 兵種相剋
- 衝鋒：騎兵速度 > 6 m/s 接觸敵兵時造成衝擊傷害（衝鋒加成 × 速度係數）並把目標撞倒；之後 3 秒內衝鋒效果遞減。
- 拒馬：堅守中的長槍兵正面被騎兵衝鋒 → 騎兵吃 3 倍反傷、衝鋒無效。

### 3.2 遠程

- 弓兵每 4 秒齊射（整團分散在 1 秒內放箭，畫面會有一片箭雨），弩兵每 6 秒。
- 箭矢是真的拋物線投射物；落點依距離有散布（距離越遠越散），落地時打中半徑 1 m 內的士兵（可能誤傷友軍，傷害 ×0.5）。
- 盾牌：刀盾兵正面受箭 −50%；散陣 −40%。
- 彈藥：弓兵 30 輪、弩兵 20 輪；耗盡只能肉搏。本陣附近可補給（糧況斷糧時不補）。

### 3.3 死亡

- 士兵生命歸零 → 播倒地動畫，屍體保留在戰場（上限 8,000 具，超過從最早的淡出），戰場會越打越「寫實」。
- 武將生命歸零 → 陣亡（或被擊退，依劇本），觸發全軍士氣事件。

## 4. 士氣（核心）

軍團士氣 0–100，基礎值 70（精銳 80、新兵 55）。

| 來源 | 變化 |
|---|---|
| 每損失 1% 兵力 | −0.8（即時） |
| 10 秒內損失 > 10% | 額外 −10 驚嚇 |
| 被側擊／背襲（交戰中） | −2／−4 每秒 |
| 被衝鋒撞上 | −8 驚嚇 |
| 箭雨下（每波） | −1（有盾 −0.5） |
| 局部兵力劣勢 > 2 倍 | −1 每秒 |
| 50 m 內友軍潰逃 | −6（一次） |
| 50 m 內敵軍潰逃 | ＋4（一次） |
| 武將在 40 m 內 | 回復 ＋1.5 每秒、上限 ＋10 |
| 我方武將陣亡 | 全軍 −20，其親衛 −40 |
| 敵方武將陣亡 | 全軍 ＋10 |
| 高地 | 回復 ＋0.5 每秒 |
| 附近起火 | −2 每秒 |
| 糧況 | 見 03（吃緊、斷糧有持續流失與上限） |
| 未交戰 | 往基礎值回復 ＋1 每秒 |

| 狀態 | 士氣 | 效果 |
|---|---|---|
| 高昂 | ≥ 80 | 攻擊 ＋10% |
| 穩定 | 35–79 | — |
| 動搖 | 15–34 | 攻擊 −15%，旗號閃黃 |
| **潰逃** | < 15 | 脫離控制，往己方地圖邊緣逃跑；被追擊傷害 ×1.5 |
| 重整 | 潰逃後脫離戰鬥 15 秒且士氣回到 30 | 可重新控制；第 3 次潰逃＝**潰散**，直接逃出戰場 |

**連鎖崩潰**：潰逃會讓附近友軍 −6 → 可能連鎖。這是「燒糧後全線崩潰」的引擎。

全軍士氣 ＝ Σ(未潰逃軍團士氣 × 兵力) ／ 開戰時總兵力 × 100（顯示用）；所有軍團潰逃／全滅即戰敗。

## 5. 體力

0–100：奔跑 −2/s、衝鋒 −4/s、肉搏 −1/s、步行 −0.2/s、靜止 ＋1.5/s（受糧況影響）。
< 30 疲憊：速度 −20%、攻防 −15%；< 10 力竭：不能奔跑。

## 6. 地形

| 地形 | 效果 |
|---|---|
| 高地 | 打下坡 ×1.15、射程 ＋15%、視野 ＋、士氣回復 ＋ |
| 森林 | 移動 −30%（騎兵 −50%）、受箭 −30%、可埋伏（50 m 外看不見） |
| 淺灘 | 移動 −40%、防禦 −20% |
| 河流 | 無法通行（只能走橋、淺灘） |
| 道路 | 移動 ＋15%（輜重車只走道路） |
| 營寨柵欄 | 阻擋；可被攻擊破壞 |

## 7. 視野

- 每個軍團視野 150 m（森林中 60 m、高地 ＋40 m）。
- 敵軍只有被看見時才顯示；藏在森林的敵軍要 50 m 內才發現。
- 不做格子迷霧遮罩（地形永遠可見），只隱藏敵軍 → 畫面乾淨、仍有伏兵與奇襲。
