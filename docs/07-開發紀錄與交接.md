### 基本流程
主選單 → 出征 → 戰役地圖選一場 → 簡報（選難度）→ 部署（拖曳／右鍵拉戰線）→ 開戰 → 結算三星

### 操作重點
| 操作 | PC | 手機 |
|---|---|---|
| 選取 | 左鍵點軍團／頭上徽章／下方卡片；框選；Shift 加選 | 點卡片或徽章 |
| 移動 | 右鍵點地面（雙擊右鍵＝奔跑） | 點地面 |
| 拉戰線 | **右鍵按住拖曳** | 長按地面後拖曳 |
| 攻擊 | 右鍵點敵軍；右鍵點敵方糧倉＝縱火 | 點敵軍 |
| 暫停 | 空白鍵（暫停中可下令） | ⏸ |
| 地形圖 | V 鍵／右上「🗺 地形」 | 同 |

## 5. 測試

```bash
npm test                                                     # 單元測試＋五場劇本煙霧測試
BALANCE=1 npx vitest run tests/balance.test.ts --silent=false # 平衡量測（兵種對戰、官渡燒糧、AI 對 AI）
```

平衡量測（2026-10-02）：

| 對戰 | 結果 |
|---|---|
| 刀盾對刀盾（正面） | 接戰約 50 秒後一方潰逃，雙方傷亡約三成五——正面是消耗戰 |
| 夾擊（側後再加一團） | 約 25 秒崩潰 |
| 重騎衝刀盾 | 4 秒內刀盾潰逃，騎兵幾乎無損 |
| 重騎衝堅守長槍 | 騎兵反吃三倍傷害、潰逃 |
| 弓射長槍／刀盾（2 分鐘） | 約 30%／4%（盾牌擋箭） |
| 官渡燒烏巢 | 焚毀後袁軍全軍士氣 64 → 個位數、大量潰逃 |
