# 01 — 玩法與操作

---

## 1. 一場戰役的流程

```
戰役地圖（CoC 式關卡節點）→ 戰前簡報（史實背景＋目標＋三星條件）
  → 部署階段：在己方部署區拖放軍團卡、調整陣型與朝向（可略過用預設佈陣）
  → 開戰（號角＋戰鼓）：即時指揮，可暫停下令
  → 結算：勝／敗、三星、雙方傷亡、燒糧、武將戰功
```

| 階段 | 時長 | 玩家在做什麼 |
|---|---|---|
| 部署 | 不限時 | 卡片列拖到部署區（藍色區域）；拖曳已放置軍團改位置；右鍵拖曳改寬度與朝向；伏兵卡可放進森林 |
| 接觸前 | 1–2 分 | 調整戰線、派騎兵繞後、弓兵上高地 |
| 主戰 | 4–10 分 | 頂住正面、抓側翼、保護弓兵、找空檔偷襲糧倉 |
| 收尾 | 1–2 分 | 敵軍連鎖潰逃，追擊（追擊潰兵可擴大戰果） |

## 2. 勝負條件

| 條件 | 說明 |
|---|---|
| **敵全軍潰散**（主要） | 敵方所有軍團潰逃或全滅（全軍士氣歸零） |
| 擊殺敵主帥 | 部分劇本：主帥陣亡 → 敵全軍士氣 −40，通常直接崩潰 |
| 攻佔本陣 | 部分劇本：己方軍團在敵本陣 25 m 內停留 20 秒且無敵軍防守 |
| 堅守時限 | 部分劇本：守住指定時間 |
| 戰敗 | 己方全軍潰散、主帥陣亡（劇本設定）、本陣被佔 |

三星評價（每場劇本自訂，通常是）：★ 勝利；★★ 完成戰役特色目標（如 6 分鐘內焚燒烏巢）；★★★ 己方傷亡低於 X%。

## 3. 操作

### 3.1 PC

| 操作 | 效果 |
|---|---|
| 左鍵點旗號／士兵／卡片 | 選取軍團（Shift 加選、Ctrl 點卡片＝選同兵種） |
| 左鍵拖曳框選 | 多選 |
| 雙擊卡片 | 鏡頭跳到該軍團 |
| 右鍵點地面 | 移動（保持陣型，朝移動方向） |
| **右鍵拖曳** | 畫出新的戰線：拖曳長度＝陣寬、方向＝朝向；多選時自動分配並排 |
| 右鍵點敵軍 | 攻擊（騎兵自動衝鋒；弓兵自動射擊） |
| 右鍵點敵方糧倉／本陣 | 進攻／縱火 |
| 雙擊右鍵 | 奔跑移動（消耗體力） |
| WASD／方向鍵／畫面邊緣 | 平移鏡頭 |
| 滾輪 | 縮放；Q／E 或中鍵拖曳旋轉 |
| 空白鍵 | 戰術暫停（暫停中可下令） |
| `1` `2` `3` | 0.5×／1×／2× 速度 |
| Ctrl＋數字／數字 | 編隊／叫出編隊 |
| `R` 奔跑切換、`H` 停止、`G` 原地堅守、`F` 自由射擊切換、`T` 切換陣型、`Backspace` 撤退 |  |
| `D` | DEV 微調工具（`?dev=1` 時） |

### 3.2 手機（橫向）

| 操作 | 效果 |
|---|---|
| 點卡片／旗號 | 選取（再點一次取消）；卡片列左側「多選」開關 |
| 點地面 | 移動；點敵軍＝攻擊 |
| 長按地面後拖曳 | 畫戰線（寬度＋朝向） |
| 單指拖曳空地 | 平移；雙指縮放／旋轉 |
| 畫面按鈕 | 暫停、速度、奔跑、停止、陣型、武將技 |

### 3.3 軍團指令

| 指令 | 說明 |
|---|---|
| 移動／奔跑 | 奔跑快 50%，每秒 −2 體力 |
| 攻擊 | 自動接近並交戰；騎兵速度夠時觸發衝鋒 |
| 停止 | 原地停下並面向當前方向 |
| 堅守 | 不追擊、不被引誘；槍兵堅守＝拒馬陣（防騎兵衝鋒） |
| 自由射擊 | 遠程兵自動射擊射程內最近敵軍（預設開） |
| 陣型 | 橫陣（預設）／方陣（防側擊）／鋒矢（騎兵、衝擊＋）／散陣（減少箭矢傷害） |
| 撤退 | 有序後撤（不算潰逃，士氣不再下降但移動慢） |
| 武將技 | 見 04 |

## 4. 鏡頭

- 透視鏡頭，預設俯角 52°、FOV 40°（CoC 式斜俯視），高度 40–320 m 可縮放。
- 最近可貼近到看清士兵揮刀（俯角自動變小到 35°，像電影鏡頭）；最遠可看全戰場。
- 可旋轉 360°；限制在地圖邊界內。
- 事件鏡頭：燒糧、武將陣亡、敵軍崩潰時跳出小視窗或短暫慢動作（可在設定關閉）。

## 5. HUD（CoC 風格）

```
┌────────────────────────────────────────────────────────────────┐
│ [官渡之戰]  07:32      我軍士氣 ███████░░ 敵軍士氣 ███░░░░░    [軍令 ⚡7/10] [⏸][1×][⚙] │
│ 糧況：我軍 🍚充足   敵軍 🍚斷糧！                                    [小地圖]  │
│                                                                        │
│                     （戰場；每個軍團頭上浮著旗號＋兵種圖示＋兵力）               │
│                                                                        │
│        [指令列：移動 奔跑 停止 堅守 陣型 撤退 ｜ 武將技]                      │
│ [卡][卡][卡][卡][卡][卡][卡][卡]           ｜ [計策卡][計策卡][計策卡]              │
└────────────────────────────────────────────────────────────────┘
```

- **軍團卡**：CoC 部隊卡造型（圓角厚框、粗描邊數字、底部兵力）；卡片上有士氣環（綠→黃→紅）、體力細條、狀態角標（⚔交戰、💨奔跑、⚠動搖、🏳潰逃、🍚斷糧）。
- **計策卡**：右側，CoC 法術卡造型，標示軍令點消耗，點下後在地圖上選目標。
- **事件橫幅**：畫面中央大字（粗描邊、金色），例「烏巢糧倉起火！袁軍軍心大亂」。
- **全軍士氣條**：頂部雙方對比條，類似 CoC 的摧毀百分比。
- **小地圖**：右上，顯示地形、雙方軍團、糧倉、本陣；點擊跳鏡頭。
- 所有 HUD 元件位置都在 `LAYOUT_PC`／`LAYOUT_MOBILE`，DEV 工具可拖曳調整並匯出（見 05）。
