## 1. 技術棧

| 層 | 選擇 |
|---|---|
| 建置 | Vite ＋ TypeScript（strict） |
| 3D | Three.js（WebGL2）：InstancedMesh、VAT 頂點動畫、自訂地形與水 shader |
| UI | 原生 DOM ＋ CSS（疊在 canvas 上），CoC 式卡片與厚描邊字 |
| DEV | lil-gui ＋ 自寫 HUD 拖曳層 |
| 音效 | WebAudio 程式合成（戰鼓、號角、兵刃、箭雨、火焰、環境聲），不依賴音檔 |
| 測試 | Vitest：陣型、尋路、士氣、糧草、戰鬥模擬 |
| 部署 | GitHub Actions → `gh-pages` 分支 → https://wenbatman33.github.io/warGame/ |

## 3. 模擬

- 固定 30 Hz；渲染每幀以 (上一步, 這一步) 插值士兵位置，60 fps 平滑。
- 士兵存成結構陣列（Float32Array／Int32Array，容量 12,000），軍團是一般物件。
- 空間雜湊（4 m 格）做鄰近查詢：分離力、找最近敵兵、箭矢命中。
- 尋路：4 m 格的導航格網（河流、懸崖、建築不可走；森林、淺灘有移動成本），A* ＋ 視線拉直；軍團中心走路徑，士兵追陣位。
- 系統每步順序：指令 → 軍團移動 → 士兵轉向／移動 → 分離 → 近戰 → 投射物 → 士氣 → 糧草 → 火焰 → 視野 → 勝負。

## 4. 渲染與效能預算

| 項目 | 做法 | 預算 |
|---|---|---|
| 士兵 | 每兵種 1 個 InstancedMesh；VAT 貼圖存所有動畫格；實例屬性：隊伍色、動畫列、起始時間、速度 | 5,000 名、< 15 draw calls |
| 馬 | 騎兵 ＝ 人＋馬合成一個模型（同一份 VAT） | 含在上面 |
| 屍體 | 同 InstancedMesh、停在倒地最後一格 | 上限 8,000 |
| 箭矢 | InstancedMesh，CPU 更新位置 | 同時 3,000 支 |
| 地形 | 256×256 頂點高度場、頂點色＋程式噪聲草地 shader、道路與泥土用 splat | 1 draw |
| 植被 | 樹（實例化，風擺 shader）、草叢（實例化） | 樹 2,000、草 30,000 |
| 陰影 | 1 盞方向光 2048 陰影圖，跟著鏡頭 | 手機可關 |
| 目標 | 桌機 60 fps（5,000 兵）；手機 30 fps（中畫質） | 模擬每步 < 6 ms |

畫質分級：高（陰影 2048＋草叢＋全部屍體）／中（陰影 1024＋草叢減半）／低（無陰影、無草叢、屍體 2,000）。

## 5. 美術風格（CoC 式）

- **光**：暖黃主光（約 45° 斜射）＋ 天空藍／草地綠半球補光；ACES tone mapping；柔邊 PCF 陰影；遠景淡霧。
- **色**：飽和但不刺眼的綠草、暖褐泥土路、青綠河水（岸邊白色泡沫）、灰藍岩壁；勢力色鮮明（魏藍、袁金黃、蜀綠、吳紅）。
- **模型**：比例接近真人（頭身 1:6），但輪廓厚實、邊角圓潤；盔甲上隊伍色占比大，遠看分得出敵我；兵器剪影放大一點以便辨識兵種。
- **道具**：帳篷、柵欄、望樓、穀倉、麻袋堆、旗幟、篝火、拒馬、輜重車——都是程式建模的厚實低多邊形。
- **地圖邊框**：外圍一圈森林與山（像 CoC 地圖的邊緣），讓戰場像一塊立體沙盤。
- **AI 生圖**（codex image_gen）：Logo、主選單背景、戰役地圖底圖、武將頭像、計策卡圖示。兵種卡圖示由遊戲內 3D 模型即時算圖產生，保證和戰場一致。

## 6. 音效（程式合成）

戰鼓（開戰、擂鼓計策）、號角（衝鋒、撤退）、兵刃碰撞（依交戰人數疊加的「戰場轟鳴」環境層）、箭雨呼嘯、馬蹄（依騎兵速度）、火焰劈啪、人聲吶喊（噪聲＋共振峰合成）、UI 點擊。音量依鏡頭距離衰減。

## 7. DEV 微調工具（必備）

- 開啟：網址 `?dev=1` 後按 `D`，或點右下角齒輪。預設關閉、不影響正式畫面。
- **HUD 版面**：所有 HUD 元件可直接用滑鼠拖曳位置、拉滑桿改大小／縮放／字級／透明度；PC／手機／平板三套 `LAYOUT` 分開調整。
- **鏡頭與光線**：俯角、FOV、縮放範圍、主光角度與顏色（色票）、補光、霧、陰影。
- **戰鬥數值**：各兵種速度、攻防、射程；士氣與糧草係數；即時生效。
- **劇本物件**：拖曳糧倉、本陣、部署區、軍團起始位置。
- **狀態觸發**：立刻焚燒敵／我方糧倉、觸發斷糧、全軍潰逃、勝利／失敗結算畫面、慢動作、武將陣亡、在游標處生成軍團、開關 AI、顯示導航格網與陣位。
- **💾 匯出**：把目前所有調整後數值輸出成 JSON（複製到剪貼簿＋下載）；Claude 讀到後寫回 `src/data`／`LAYOUT_*` 並 commit。
