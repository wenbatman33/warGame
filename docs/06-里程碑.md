# 06 — 開發里程碑

> 每個里程碑完成 → 跑測試與建置 → 瀏覽器實測截圖 → commit ＋ push（Actions 自動部署）。

| 里程碑 | 內容 | 驗收 |
|---|---|---|
| **M0 規劃與骨架** | 規劃書 docs/00–06、Vite＋TS＋Three 骨架、Actions 部署 | `npm run build` 通過；推上 GitHub |
| **M1 千軍戰場** | CoC 式地形／水／植被／光影、RTS 鏡頭、程式建模士兵＋VAT 動畫、5,000 名士兵實例化、DEV 工具雛形 | 桌機 5,000 兵 60 fps；可縮放旋轉；DEV 可調光與鏡頭 |
| **M2 軍團指揮** | 軍團與陣型、導航格網＋A*、選取（點／框選／卡片）、移動、右鍵拖曳畫戰線、陣型切換、旗號 | 多選拖曳畫戰線時士兵正確排成新陣 |
| **M3 戰鬥與士氣** | 近戰、弓弩箭雨、騎兵衝鋒與拒馬、死亡與屍體、士氣／潰逃／重整／連鎖崩潰、體力、武將與技能 | 兩軍對撞能自然打出「一翼崩潰 → 連鎖潰逃」 |
| **M4 糧草與 AI** | 糧倉、本陣、輜重車、縱火與火焰、糧況效果、敵軍 AI 指揮官（含劫糧）、視野與伏兵 | 燒掉敵糧倉後敵軍明顯崩潰；AI 會劫你的糧 |
| **M5 CoC 式介面** | 主選單、戰役地圖、簡報、部署階段、軍團卡、計策卡、小地圖、事件橫幅、結算三星、設定 | 從主選單一路玩完一場 |
| **M6 真實戰役** | 官渡（招牌）、赤壁烏林、合肥逍遙津、夷陵、街亭、自訂會戰 | 每關可勝可敗、三星條件正確 |
| **M7 打磨** | AI 生圖（Logo、頭像、背景）、程式音效與配樂、粒子（塵土、火、煙）、效能分級、手機操作 | 手機可玩完一關 |

## 風險

| 風險 | 對策 |
|---|---|
| 5,000 兵 CPU 模擬太慢 | SoA ＋ 空間雜湊；遠離戰線的士兵降頻更新；必要時搬進 Web Worker |
| 手機 GPU 撐不住 | 畫質分級、關陰影與草叢、屍體上限 |
| AI 太笨或太強 | 角色制＋難度參數；DEV 可即時開關與觀戰 |
| 程式建模士兵不夠精緻 | 先確保遠景剪影辨識度；近景加細節（披風、羽飾、盾紋） |
